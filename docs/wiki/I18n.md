# I18n
Kod: `src/i18n.rs`. Bağlı: [[Ui]], [[Config]], [[Cli]], [[AiClient]].

- Dil süreç genelinde bir atomik ayar (`i18n::set/get`): çekirdek tipler (`Category::label`, `Kind::label`, `Skip::message`, `AiError`) ve UI aynı dili konuşur.
- `t("TR", "EN")` düz metin, `tf!("TR {}", "EN {}", args)` biçimli metin (iki şablon da literal; `{n}` yakalamaları çalışır), `tr!(expr, expr)` serbest ifade.
- `resolve("auto"|"tr"|"en")`: auto = Windows'ta `GetUserDefaultLocaleName` (FFI), diğerlerinde `LC_ALL/LANG`; `tr*` → Türkçe, aksi halde English.
- Ayar: `[ui] language` (Ayarlar → Dil / Language, anında uygulanır, Kaydet kalıcı yapar). `main` açılışta uygular.
- Taramalar kural gerekçesini (Türkçe) DB'ye yazar; UI **kural kimliğinden** (`rule_reason`) çevirir → eski taramalar da güncel dilde görünür. Yeni kural eklenirse `rule_reason` tablosuna ve testine eklenmeli.
- Onay sözcüğü: `confirm_word()` = SIL / DELETE (UI + CLI aynı).
- GOTCHA: dil testleri global durumu değiştirir → `i18n::tests` içinde Mutex ile serileştirilir.
